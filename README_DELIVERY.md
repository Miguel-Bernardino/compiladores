Entrega — Etapa 6 (LEX)

Conteúdo desta pasta `6.LEX`:

1. Fonte da implementação: o código-fonte está no repositório (arquivos .py na raiz e nas pastas `LexerScanner`, `Reserved`, `Symbol`, `Token`).
2. Scripts para execução rápida:
   - `run_lexer.bat` — executa o scanner no Windows
   - `run_lexer.sh`  — executa o scanner em Linux/macOS
3. Instruções de instalação e criação de executável: `INSTALL.md`
4. Atualização do projeto desde a primeira entrega: `PROJECT_UPDATE.md`
5. Arquivo de entrega preenchível: `ENTREGA.txt`

Uso rápido (Windows):

1. Abra um terminal na pasta do projeto.
2. Execute:

```
run_lexer.bat
```

Isso roda `python main.py MeuTeste` e gera `MeuTeste.LEX` e `MeuTeste.TAB` na mesma pasta.

Se desejar que eu compacte os arquivos fonte aqui dentro ou gere um executável, diga qual formato (zip, exe via pyinstaller) prefere e eu preparo as instruções ou artefato.
